# 智慧树自动连播（zhihuishu-auto-next）

> 一个用于智慧树 / 知到（zhihuishu.com）学习页的 Tampermonkey（油猴）用户脚本：当前视频播完后自动展开单元、切换到目录中的**下一个视频**，并在整页刷新后仍能记住进度。支持倍速锁定、弹题自动关闭、切后台保持播放。

> ⚠️ **仅供学习与自动化技术研究使用。** 请遵守你所在学校及智慧树平台的相关规定，合理、诚信地使用本脚本。因使用本脚本产生的一切后果（包括但不限于学习记录异常、账号受限等）由使用者自行承担。

---

## ✨ 功能特性

- **自动连播**：监听视频 `ended` 与片尾进度，自动点击左侧目录中的下一条视频。
- **自动展开折叠单元**：下一条位于折叠的「知识单元 / 模块」内时，自动展开后再点击。
- **整页刷新记忆**：学习进度（当前条目）写入 `localStorage`，并通过 DOM 路径 + 标题双重校验，刷新后自动恢复定位。
- **多重定位兜底**：依次按「持久化路径 → 标题 → URL 资源 ID → 当前高亮底色」还原当前视频。
- **倍速锁定**：支持 `1.0x / 1.25x / 1.5x` 循环切换，选择持久化，并在加载新视频、播放器重置倍速时自动纠正。
- **弹题自动关闭**：检测到单选 / 多选 / 判断等随堂弹题时自动关闭并继续播放。
- **切后台保持播放**：标签页失焦或页面隐藏时自动尝试恢复播放（可配置）。
- **可折叠状态浮层**：右下角显示正片进度、当前条目、下一条标题与运行日志。
- **调试模式**：开启后显示「强制播放 / 复制诊断 / 条目数组检视」，便于排查目录识别问题。

脚本不依赖任何第三方库，单个 `.user.js` 文件即可运行，`@grant none`。

## 📦 安装

### 环境要求

- 浏览器：Chrome、Edge、Firefox 等支持用户脚本的现代浏览器
- 扩展：[Tampermonkey（油猴）](https://www.tampermonkey.net/)（或兼容的用户脚本管理器，如 Violentmonkey）

### 安装步骤

1. 安装浏览器扩展 **Tampermonkey** 并启用。
2. 打开本仓库中的 [`zhihuishu-auto-next.user.js`](./zhihuishu-auto-next.user.js) 的原始文件（Raw）链接，Tampermonkey 会自动弹出安装页。
   - 也可以手动复制脚本全部内容 → Tampermonkey 面板 → 「添加新脚本」→ 粘贴保存。
3. 确认脚本已**启用**。
4. 打开智慧树的课程学习页（网址形如 `.../zhihuishu.com/.../learnPage/...`）。

> 首次使用请**手动点击一次左侧目录中的当前视频**，脚本会记录并持久化当前条目，之后即可自动连播。

## 🚀 使用说明

1. 进入课程视频学习页，右下角出现绿色标题的 **连播** 浮层。
2. 手动点击正在学习的视频条目（用于初始化定位）。
3. 正常播放即可：视频结束后脚本会自动定位并切换到下一条。
4. 可通过浮层按钮操作：
   - **手动下一条**：立即切换到下一条视频。
   - **倍速 x.xx x**：在 `1.0 / 1.25 / 1.5` 之间循环切换并锁定。
5. 点击浮层标题栏可折叠 / 展开面板。

浮层中各状态行含义：

| 显示 | 含义 |
| --- | --- |
| `正片: 05:12/12:30 ▶/⏸` | 当前正片视频的时间 / 总时长与播放状态 |
| `当前[来源]: 标题` | 当前定位到的目录条目及其判定来源 |
| `下一条 → 标题` | 即将自动切换到的下一条视频 |

**当前条目标注来源**：`本次点击`、`持久记忆`、`持久记忆(标题)`、`URL-ID`、`底色兜底`、`未定位`。

## 🐞 调试模式

默认关闭调试控件。需要排查「浮层下一条与左侧目录不一致」等问题时，在浏览器控制台执行：

```js
localStorage.setItem('__zhsAutoNextV7Debug', '1');
```

然后刷新页面，浮层会额外显示：

- **🔍 条目数组检视（collectRows）**：列出脚本识别到的全部条目、下标、标签 / class、标题、可见性、当前标记（★）。
- **复制诊断**：一键复制包含网址、URL 资源 ID、持久记忆、条目数组等信息的 JSON，便于反馈问题。
- **强制播放**：对当前视频执行 `play()`。

关闭调试模式：

```js
localStorage.removeItem('__zhsAutoNextV7Debug');
```

## ⚙️ 配置项

脚本顶部的 `CFG` 对象可按需修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `interval` | `1000` | 状态轮询间隔（毫秒） |
| `autoCloseQuiz` | `true` | 是否自动关闭随堂弹题 |
| `resumeWhenBlurred` | `true` | 页面失焦 / 隐藏时是否自动恢复播放 |
| `storageKey` | `__zhsAutoNextV7` | 进度记忆在 localStorage 中的键名 |
| `speedKey` | `__zhsAutoNextV7Speed` | 倍速记忆键名 |
| `speeds` | `[1, 1.25, 1.5]` | 可循环切换的倍速列表 |
| `debug` | `false` | 是否默认开启调试模式 |
| `debugKey` | `__zhsAutoNextV7Debug` | 通过 localStorage 临时开启调试的键名 |

## 🔍 工作原理（简述）

1. **条目识别**：在左侧目录中匹配「必学/选学 x/x」进度标记，取最深层匹配节点并向上归并为「行」，再按左侧栏位置、可见性与 DOM 结构过滤，最终按文档顺序得到条目数组。
2. **当前定位**：结合 localStorage 中保存的 DOM child-index 路径、标题、URL 资源 ID 与条目高亮底色进行多级还原。
3. **自动切换**：视频结束 → 取条目数组中的下一条 → 若在折叠单元内则先展开 → 预先持久化下一条路径 → 模拟真实鼠标事件点击（页面通常整页刷新，刷新后按记忆恢复）。
4. **倍速锁定**：监听 `loadstart / play / ratechange`，在播放器把倍速重置回 1 时异步纠正回用户设定值。

## 🧭 常见问题

**Q：浮层显示的「下一条」和左侧目录对不上？**
A：先手动点击一次左侧目录中的当前视频以校正定位；若仍不一致，开启调试模式查看「条目数组检视」，并用「复制诊断」把 JSON 反馈到 Issues。

**Q：刷新后提示「未定位」？**
A：页面结构变化可能导致保存的路径失效。手动点击一次当前视频即可重新建立记忆。

**Q：视频结束后没有自动切换？**
A：确认当前条目已正确定位（浮层不是「未定位」）；下一条在折叠单元且自动展开失败时，请用「复制诊断」反馈。

**Q：会上传我的数据吗？**
A：不会。脚本仅在当前页面运行，数据保存在本地 `localStorage`，不发起任何网络请求、不收集任何信息。
